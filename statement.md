# Problem Statement

Students often find it difficult to predict their final examination
grade based on their current marks.

The Smart Exam Grade Predictor is a Java-based GUI application that
helps students predict their grade, calculate required marks for a
target grade, and analyze their examination performance.

## Scope

The application calculates examination performance using predefined
project grading rules.

## Target Users

- College Students
- School Students

## Main Features

1. Grade Prediction
2. Target Grade Calculation
3. Performance Analysis
4. Input Validation
5. Report Generation\
